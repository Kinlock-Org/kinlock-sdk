# Contributing to kinlock-sdk

Follow the org-wide guide: [Kinlock-Org/.github CONTRIBUTING.md](https://github.com/Kinlock-Org/.github/blob/main/CONTRIBUTING.md).

Repo-specific setup: see the Quick start in `README.md` and the commands in `AGENTS.md` §8.
